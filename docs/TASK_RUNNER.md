# Колос для Windows

Колос читает описание задачи и текущий вход. При первом запуске выбранная модель превращает инструкцию в проверяемое правило. Колос сравнивает правило с эталонными результатами, сохраняет его и применяет к входу. При следующем запуске с тем же описанием Колос берёт правило из локальной памяти и работает без модели.

## Установка

1. Распакуйте `Kolos-Runner-Windows-x64.zip`.
2. Откройте `Kolos Setup` и запустите `Install.cmd`. Установка добавит «Kolos» в меню «Пуск». В архив входят интерпретатор Python и библиотека, нужная ядру Колоса.
3. Для первого урока установите или откройте нужный CLI и войдите в свой аккаунт. В окне Колоса выберите Codex или Claude Code. Поле «Модель» можно оставить пустым. Для Codex Колос ищет также CLI в установленном приложении Codex, для Claude Code — нативный `claude.exe` в `PATH` или `.local/bin`. [Claude Code CLI](https://code.claude.com/docs/en/cli-reference)

Установка находится в `%LOCALAPPDATA%\Programs\KolosRunner`. Правила и отчёты хранятся отдельно в `%LOCALAPPDATA%\Kolos\Runner`. Новая установка сохраняет эти данные. Каталог с программой можно удалить отдельно от памяти.

## Первый запуск

1. В меню «Пуск» откройте «Kolos». Нажмите **WB · первый файл**, выберите провайдер и нажмите **Выполнить**. На первом запуске вы увидите число вызовов модели и потраченные токены.
2. Закройте Колос и запустите заново. Нажмите **WB · новый файл**, затем **Выполнить**. Колос покажет результат для новых акций и ноль вызовов модели. Можно выбрать **Только локально**, если нужно запретить обучение и разрешить применение уже выученных правил.
3. Кнопка **Открыть отчёт** покажет квитанцию со статусом, результатом, отпечатками входа и правила и данными об использовании токенов. Если провайдер не сообщил часть счётчиков, в отчёте будет `null`.

Модель получает текст инструкции и поля схемы. Содержимое текущего файла и проверочные примеры Колос использует локально. Подбирайте примеры по обе стороны порога и с пограничными значениями, чтобы неверный кандидат не прошёл проверку.

## Своя задача и автоматический запуск

- Для WB начните с `app/examples/task_runner/wb-task.json`. Вход — JSON-манифест v2 с ожидаемыми акциями, временем проверки и строками выгрузки. Укажите требуемое число свежих файлов в инструкции и задайте два или более независимых проверочных примера.
- Для операций над таблицами используйте `app/examples/task_runner/table-task.json`. Укажите `columns` с типами `integer` или `text`, тип результата `list`, `number` или `mapping`, инструкцию и проверочные примеры. Доступны фильтрация, подсчёт, сумма и группировка с одним числовым условием. Вход — массив однотипных записей JSON.
- Дайте задаче стабильный `id`. Изменение инструкции, схемы или проверочных примеров создаёт новую версию правила. Меняйте только входной файл для повторных прогонов.

Из папки установленной версии в PowerShell:

```powershell
.\Kolos.cmd run .\app\examples\task_runner\wb-task.json .\app\examples\task_runner\wb-first.json --provider codex
.\Kolos.cmd run .\app\examples\task_runner\wb-task.json .\app\examples\task_runner\wb-next.json --provider none
```

Выберите `--provider claude` для Claude Code. CLI выводит JSON и возвращает `0` при успехе, `2` если выключено обучение и правило отсутствует, `1` при ошибке. Эту же команду можно поставить в Планировщик заданий Windows после того, как ваш источник подготовит JSON.

## Сборка

В корне репозитория запустите сборку на Windows x64 с обычным CPython 3.10+ и Tcl/Tk. Для сборки требуется Pillow из зависимостей ядра Колоса.

```powershell
py -3 -B packaging/windows/build_runner.py .local-data/artifacts/Kolos-Runner-Windows-x64.zip
```
