# Neural Studio — ПК-оформление №2

## Что реализовано

Нативная оболочка всей программы Glaz, без WebView, внешнего браузера, Node.js
или новой копии алгоритма. В `Glaz/main.py` по умолчанию создаётся
`NeuralStudioApp`, наследующий существующий `IntegratedScreenCaptureApp`.
`run_main.bat` не меняется. Старый интерфейс доступен через `run_classic.bat`.

Дизайн №2: сине-графитовая основа, лиловый акцент, компактная боковая навигация,
большой холст, плавающий инспектор, мини-карта, постоянный нижний терминал.

Переоформлены основной экран, пики/лупа/элементы, терминал и его кнопки,
настройки зрения, обучение, эксперименты, память, существующие диалоги целей,
языка и I/S. Стандартные диалоги выбора файла и системные предупреждения
оформляются самой Windows. Это нативная адаптация макета, не его HTML-скриншот.

## Запуск

1. Закройте Glaz. Сохраните резервную копию проекта и собственных изменений.
2. Обновите полную ветку `feature/browser-graph-lab` либо примените архив
   обновления поверх уже установленной версии с встроенными нейронами
   (`580b74d1` или совместимой). Это обновление, а не самостоятельный exe.
3. Запустите прежний `run_main.bat`. В заголовке появится Neural Studio.
4. Движок «Состояния и цели (ПК)» и управление ПК включены при запуске.
   Открыт вид «Пики и элементы», терминал занимает нижнюю половину рабочего
   пространства. Выберите монитор и включите захват.
5. Работайте как раньше: команда → 3 → действия → Esc → 5 → 1.
6. Переключайтесь между «Нейроны» и «Пики и элементы». Ввод и процесс Kolos
   остаются общими. Распознавание при скрытых пиках продолжает работать.

Для нового оформления дополнительные зависимости не требуются: используются
Tk/ttk и уже применяемый в Glaz Pillow. Новых шрифтов/сетевых ресурсов нет.

Glaz использует движок «Состояния и цели (ПК)». Встроенный нейронный просмотр читает снимки активного сеанса.

## Управление

- Узкая левая панель: Работа, Учить, Опыты, Память, Опции. Кнопки имеют подписи,
  доступны с Tab/Enter и открывают реальные действия/диалоги, не муляжи экранов.
- Обычная строка ввода: Enter или «Передать в Kolos» отправляют одну и ту же
  строку один раз в существующий процесс. Обучающие кнопки — прежние команды.
- Отправленная строка остаётся в терминале зелёным после `>`. При ошибке
  отправки текст остаётся в поле ввода, чтобы его можно было отправить повторно.
- Над прокручиваемым выводом закреплена зелёная строка «Задача: …». Длинный
  текст переносится по ширине терминала. Новая текстовая задача заменяет
  прежнюю; запись, подтверждение, пауза, стоп и другой служебный ввод её не
  меняют. Строка сохраняется при переключении рабочих вкладок, даже если
  исходная запись уже ушла из истории терминала.
- Вкладка «Что умеет Colossus» показывает задачи из сохранённой памяти States:
  запись → Esc → 5 → 1. Видны число подтверждённых демонстраций и их действия.
  Список обновляется автоматически; повторные записи одной фразы объединяются.
  Ввод команды, подготовка через 5 и `/expose` сами по себе задачу не добавляют.
- Параметры зрения перенесены в «Настройки»: чувствительность, масштаб,
  инверсия, пиксели сегмента, скриншоты и контуры. Их исходные переменные сохранены.
- Инспектор можно скрыть; кнопка «Вписать» учитывает занимаемую им ширину.
- Мини-карта строится по отображаемым вершинам; нажатие передвигает камеру графа.
- «Заморозить рисунок» не останавливает алгоритм. «Пауза» и F9 управляют States.
- Интервал 0,1–3 с в терминале меняется только по действию пользователя.
- Поиск/слои фильтруют рисунок, не память. Прежний лимит рисунка 300 вершин
  остаётся явно показанным, большая память не удаляется.
- При запуске States разрешение на управление ПК включено. При смене движка
  и F9/STOP оно сбрасывается; открытие графа его не меняет. Повторное включение
  галочки требует подтверждения для текущего сеанса.

В настройках очистка объектов вынесена из повседневного экрана. Теперь она
запрещена во время захвата, записи и неподтверждённой попытки, требует отдельного
подтверждения с предупреждением об удалении скриншотов/влиянии на прежние ID.
По умолчанию выбран отказ. Само обновление ничего не очищает.

## Совместимость

Математические модули, структуры памяти, моторика, механизм квитанций и
наблюдения не меняются. Схемы обучения и ограничения языкового механизма
прежние; оформление не добавляет понимание неизвестных команд.

Режимы 1024×680 и 1100×768 поддерживаются для основных кнопок; на большем
мониторе больше места для графа. Размеры следуют масштабированию Tk/Windows.
Точное совпадение пикселей при любом DPI не заявляется.

На одном мониторе окно Glaz всё ещё закрывает приложение под ним. Нужен
видимый целевой участок рядом либо другой монитор.

## Проверки

`python -m unittest discover -s tests/desktop -v` — прежние алгоритмы,
общая база 1–12, потактовое JS/Python сравнение и новые статические проверки.

`KOLOS_STUDIO_GUI_SMOKE=1` и запуск `test_neural_studio.py` — настоящие Tk-виджеты
с подменёнными границами ОС: единый терминал, переключение, читабельность команд
на 768p, инспектор, мини-карта, тема диалогов, разрешение/STOP, настройки и очистка.

Windows smoke из `test_windows.py` запускает настоящий NeuralStudioApp с реальным
подпроцессом; предыдущая отдельная проверка наблюдаемого Win32-поля сохранена.
Снимки интерфейсных тестов маркируются как тестовые, не как исполнение на ПК
пользователя. Старый интерфейс также сохраняет свои проверки.
