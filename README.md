# Колос (Kolos)

Колос помогает повторять действия с доступными полями и кнопками в приложениях Windows. Покажите порядок действий один раз, а при следующем выполнении задачи Колос прочитает свежие данные, повторит шаги и проверит результат. Сохранённая задача выполняется локально.

В первом примере вы научите Колос переносить текст из одного поля в другое и сохранять форму. Затем поменяете текст и увидите, как Колос повторяет тот же порядок действий с новой строкой.

[**Скачать Колос (.zip)**](https://github.com/ks-spb/Kolos-Community/archive/refs/heads/main.zip)

## Установка на Windows

1. Установите Python для Windows. Тестовый сценарий проверен с Python 3.14. Откройте PowerShell и убедитесь, что команда `py -3 --version` показывает версию Python. [Скачать Python](https://www.python.org/downloads/windows/)
2. Распакуйте ZIP и откройте папку `Kolos-Community-main`.
3. Запустите `install_states.bat`. Он установит зависимости и проведёт четыре встроенные проверки. Дождитесь результатов с `"passed": true` и закройте окно установки.
4. Запустите `run_classic.bat`. Откроется окно Glaz, в котором доступен диалог для первого показа.

## Покажите первую задачу

### Откройте тестовую форму

1. В терминале Kolos в главном окне Glaz откройте **Опыты и инструменты → Рабочий эпизод и роли**.
2. В диалоге нажмите **Тестовое окно**. Когда появится форма `Kolos working episode`, вернитесь в диалог, нажмите **Окна**, выберите эту форму в списке и нажмите **Прочитать**. В таблице появятся `Source 1`, `Target 1`, `Saved 1` и `Save`.
3. В главном окне Glaz проверьте флажок **Разрешить управление ПК**. Если он снят, включите его и подтвердите разрешение для текущего сеанса.

### Запишите показ

В диалоге оставьте фразу **«Перенеси содержимое поля и сохрани»** и нажмите **Начать показ**. Выбирайте объекты в таблице диалога и нажимайте указанные кнопки по порядку.

| Выберите в таблице | Нажмите в диалоге | Результат |
| --- | --- | --- |
| `Source 1` | **Прочитать → значение** | Колос прочитает текст в `v0`. |
| `Target 1` | Выберите `v0` и нажмите **Ввести значение** | Текст появится в `Target 1`. |
| `Save` | **Активировать** | Сохранённый текст появится в `Saved 1`. |

Нажмите **Сохранить показ**. В терминале появится сообщение о сохранении рабочего эпизода.

### Повторите на новых данных

В самой тестовой форме замените текст в `Source 1` на `Заявка 6143`. Вернитесь в диалог и нажмите **Выполнить фразу** с той же фразой. Показ сработал, если `Target 1` и `Saved 1` получили `Заявка 6143`.

Для остановки используйте **F9** или кнопку **СТОП F9** в диалоге. Для первых опытов используйте тестовую форму и вымышленные значения.
