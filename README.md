# Колос (Kolos)

Колос запоминает показанные операции, повторяет их на новых данных и проверяет результат. Основной интерфейс на Windows открывается через Glaz. Для разработки и проверки модели есть веб-лаборатория в [`web`](web/README.md).

На Windows один раз запустите `install_states.bat`, затем откройте `run_main.bat`. Движок также можно проверить командой `python -m kolos_states.cli --selftest`.

Код доступен по [лицензии Колоса](LICENSE). Личное и внутреннее использование бесплатно. Для платного обслуживания сторонних клиентов нужен отдельный договор, в том числе когда клиенту передаётся только результат работы.

## Проверка переноса навыков и сравнение с планировщиком

Для сравнения исполнения кластерных операций моделью со скиллом, скриптом и
Колосом есть отдельный [локальный replay-эксперимент](docs/CLUSTER_REPLAY_EXPERIMENT.md).
Он использует сохранённые before/after, не изменяет рекламу и измеряет реальные
токены модели на полностью обезличенных входах.

Продолжение: [изменение процедуры, адаптация и перенос](docs/CLUSTER_ADAPTATION_EXPERIMENT.md)
с новым обязательным шагом возврата, сохранением старых навыков и перезапуском памяти.

Изолированный воспроизводимый эксперимент: обучение отдельным переходам,
новые комбинации, обучение изменившемуся результату, сохранение штатным Store
и загрузка в новом процессе. Контрольный исполнитель — Dijkstra по той же
выученной памяти с общими моторными проверками и правилом пластичности.

```powershell
python -B -m kolos_states.transfer --seed-start 2000 --worlds 20 --output tests/desktop-output/transfer-selection-v2
```

[Исправление выбора и новая выборка](docs/TRANSFER_SELECTION_FIX.md),
[первоначальный эксперимент](docs/TRANSFER_EXPERIMENT.md). Полные действия, ошибки,
изменения весов и снимки памяти сохраняются в указанном каталоге. Это модельный
стенд; произвольные приложения, зрительное распознавание и внешние LLM-агенты
этим экспериментом не проверяются.

Дополнительное сравнение на шести новых семействах топологий и при смене цели:
[методика и результаты](docs/TOPOLOGY_GOAL_EXPERIMENT.md).

```powershell
python -B -m kolos_states.topology_experiment --seed-start 3000 --worlds 10 --output tests/desktop-output/topology-20261110
python -B -m kolos_states.topology_experiment.validate --directory tests/desktop-output/topology-20261110
```

## Рабочий движок и общие объекты — 09.10.2026

**Поддерживается только «Состояния и цели (ПК)». Legacy отключён.**
Запуск через `run_main.bat` по-прежнему открывает Glaz со встроенным Kolos.
Переменная `KOLOS_ENGINE=legacy` больше не включает старый движок; прямой запуск
корневого `main.py` выводит подсказку со штатной командой запуска.

Добавлены общие нейронные ансамбли объектов: разные зрительные ID (например,
50 и 63) сохраняются независимо, но после подтверждения человека возбуждают
один контекстный ансамбль. При расхождении Kolos удерживает цель и спрашивает,
а не кликает вслепую. Подтверждение сохраняется в графе, результат действия
проверяется независимо. Отдельно сохранено обучение составным образам «значок + подпись».

Вопрос открывается автоматически; повторный просмотр — **Опыты и инструменты →
Уточнение объекта**. Используйте **«Да, запомнить»**, не прежнюю кнопку «Правильно (1)».
Память v2/v3 мигрируется в v4 с резервной копией; исходные ID Glaz и SQLite-файлы
не удаляются. Уже известные команды и рабочие эпизоды сохраняются.

[План, архитектура и инструкция](docs/OBJECT_CONCEPTS.md) ·
[Результаты локальных проверок](docs/evidence/object-concepts-results.json).

Проверено: **54 новых теста**, включая отдельный Tk-диалог и прежние возможности
1–12/E13 после обучения общему объекту; 477 выполненных Python-тестов, 28 опциональных
пропущены; 237 JavaScript-тестов. Моторный цикл проверен на модели, не физическим
кликом по пользовательской папке. Область подтверждения — изученный участок задачи
и контекст окна, не универсальная взаимозаменяемость всех похожих кнопок.

## Launcher

Дополнительный запуск через `python launcher.py` открывает тот же единый
Glaz/States. Кнопка **«Запустить Колос»** запускает `Glaz/main.py`,
**«Остановить»** завершает управляемое приложение. Отдельного Legacy-процесса нет.

## Интерактивный просмотр графа памяти

Просмотрщик `graph_viewer.py` читает таблицы `tochki` и `svyazi` из вашей базы SQLite в режиме только чтения. Он группирует повторные связи одного
направления, подписывает вершины и стрелки, создаёт автономный
`kolos_graph.html` и открывает его в браузере.

Установка и запуск из корня проекта:

```bash
python -m pip install -r requirements.txt
python graph_viewer.py --database path/to/memory.db
```

Для запуска двойным щелчком используйте файл
`Запустить граф Kolos.bat` в корне проекта.

Дополнительные параметры:

```bash
python graph_viewer.py --database D:\data\memory.db
python graph_viewer.py --output D:\reports\kolos.html --no-open
```

Путь к другой базе также можно указать через `KOLOS_GRAPH_DATABASE_PATH`.
Отсутствующая база не создаётся. Существующий статический просмотрщик
`Diagram_new.py` можно запустить с собственной совместимой базой.

## Дорожная карта развития Kolos → AGI

Актуальный план развития проекта — от текущей общей памяти и обучения на демонстрациях
до внешнего учителя ChatGPT, переносимых навыков между ПК, обучения по результату,
модели мира, непрерывного обучения и независимой проверки общности:

**Этап №1 «Полноценный рабочий эпизод и роли» реализован и проверен (04.10.2026).**
E13: после одного показа Kolos читает новое содержимое источника, вводит его в
получателя, сохраняет и проверяет результат, не изменяя источник. Проверены новая
компоновка, новые локальные ID, несколько полей и восстановление памяти.

Следующий этап: **№2 «Внешний учитель: человек / ChatGPT»**. E14 — перенос на другой
ПК — относится к этапу 3 и пока не выполнен.

### Как открыть рабочие эпизоды

Обновить эту ветку, выполнить `install_states.bat` и запустить привычный
`run_main.bat`. В Glaz выбрать **«Состояния и цели (ПК)» → «Опыты и инструменты» →
«Рабочий эпизод и роли»**. Разрешение управления ПК по умолчанию выключено.

В диалоге открыть тестовое окно и прочитать его объекты. После явного разрешения
показать последовательность кнопками: Source 1 → прочитать в `v0`, Target 1 →
ввести `v0`, Save → активировать; затем сохранить показ. Изменить строку в Source 1
и выполнить ту же выученную фразу без нового обучения. Для иной компоновки:

```powershell
python -m kolos_states.episode_pad --source "Новая строка 6143" --layout 1
```

Выбрать новое окно в диалоге и повторить фразу. F9, пауза и Reset сохранены;
неподтверждённое действие автоматически не повторяется. Прежняя клавиатурная
запись остаётся отдельным форматом и не заменена новым диалогом.

Без управления ОС проверку можно запустить так:

```powershell
python -m kolos_states.episode_experiment --evidence tests/desktop-output/stage1-model.json
```

**Регрессия:** 151 тест Python/Glaz с включёнными Windows/GUI-проверками, 117 Legacy-
тестов, 224 JavaScript-теста, 120 приёмочных тестов и девять браузерных наборов
прошли. Приёмочные наборы пересекаются, это не суммарное число уникальных проверок.
Возможности 1–12 проверены на одной памяти до и после обучения новому эпизоду,
в разных порядках и после восстановления.
