# Обязательная приёмка алгоритма Kolos

Базовый набор теперь состоит из **10 возможностей**. Исходные четыре обязательных
сценария сохранены; добавлены шесть возможностей выбора результата/маршрута,
композиции, перепланирования и реакции на ошибку предсказания.

Полная матрица обучения, контрольных заданий, нейроноподобных механизмов и границ:
[CAPABILITIES.md](CAPABILITIES.md).

## Запуск

Из `web/`:

```
npm run test:acceptance
npm run test:acceptance:browser
```

Из корня:

```
python -m kolos_states.cli --acceptance
python -m unittest discover -s tests/desktop -v
```

Отдельный дорогой перебор: `npm run test:acceptance:exhaustive`.
Workflow **Kolos Algorithm Acceptance** запускает все десять, причинные
контроли, Python-паритет и браузер. Он доступен вручную и автоматически запускается
в рабочей ветке при изменениях ядра, модели среды и самих приёмочных тестов.
Косметические изменения не требуют полного прогона. Отчёт содержит commit,
область проверки и хеши файлов ядра; выбранный поднабор браузерных случаев
не выдаётся за полный прогон.

## Критерий подтверждения

Нельзя объявлять набор возможностей подтверждённым только по правильному конечному
тексту. Проверяются реальный выбор по взвешенной активации, влияние decay,
удержание целей, снятие торможения только по подтверждению, независимый прогноз,
отсутствие полного контрольного показа и неизменность долговременной памяти.

Отключение соответствующей связи/возбуждения/торможения должно менять поведение.
Это отличает рабочий механизм от декоративных сигналов поверх готового решения.

Долгие проверки не нужны на каждом косметическом изменении. Они обязательны
перед релизом и после изменения математического ядра, представления состояний,
сопоставления примеров, выбора целей, обработки квитанций или исполнения.
Четыре прежних теста по-прежнему являются минимальным неснимаемым требованием.

Симулятор, браузерный интерфейс, Python-перенос и реальный ПК — отдельные уровни
проверки. Пропуск не равен PASS. Прохождение набора не доказывает AGI или точную
биологическую модель человеческого мозга.

## Опыт 11: внутренний образ не равен внешнему подтверждению

Дополнительно обязателен `IMAGERY.md`: общие вершины содержимого, раздельные I/S,
образ без моторики, затухание при снятии поддержки, достижение образа через
прежний граф и погашение только по внешнему совпадению. `test:acceptance` включает
эти проверки; `test:acceptance:browser` проверяет их интерфейс. Понимание русского
языка в область подтверждения опыта 11 не входит.

## Опыт 12 — язык сам возбуждает образ

В обязательную приёмку добавлены `tests/language.test.mjs`, языковой отчёт,
`tests/desktop/test_language.py` с потактовым паритетом и `tests/language_browser.py`.
На вход контрольного запуска идёт только новая фраза с 1354, не готовый Goal.
Пары учат ограниченные формулировки; неизвестный синтаксис не объявляется понятым.
Полные критерии, механизм и границы: [LANGUAGE.md](LANGUAGE.md).

## Общая память: обязательная проверка интерференции

Изолированные PASS 1–12 недостаточны для заявления о совместной работе знаний.
Теперь обязательны `npm run test:shared`, браузерный `test:shared:browser` и
`python -m kolos_states.shared_experiment`: одна обученная база, один экземпляр
движка, фиксированные веса/коэффициенты на все двенадцать, несколько порядков задач,
восстановление базы, перенос между группами знаний и отрицательный контроль.
План и границы: `web/SHARED.md`. Модельные/пропущенные проверки не являются
подтверждением работы всех сценариев в реальных приложениях Windows.
