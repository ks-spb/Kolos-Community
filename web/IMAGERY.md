# Опыт 11: образ цели и восприятие — общее содержимое, разные источники

## Гипотеза и последовательность

Вместо отдельной вершины «воображаемое FIELD=2345» и её внешнего двойника
используется один набор представлений. На каждой вершине считаются независимо:

- I: внутреннее возбуждение от поддерживаемой цели;
- S: возбуждение от наблюдения среды;
- present: есть ли данный признак в текущем внешнем наблюдении.

Проверяем: внутренний образ может направлять поиск и выполнение, но ни большая I,
ни сохранившийся след S не могут подменить текущее подтверждение результата.
Это эксперимент над инженерной сетью, не доказательство человеческого воображения.

1. Сохранить ядро и обязательные возможности 1–10 без изменения их математики.
2. Включать новый механизм только операцией `imagine`; обычная `goal` остаётся прежней.
3. Повторно использовать ID изученного состояния. Для поля создать временные
   представления: поле + вхождения (позиция, символ) + конец последовательности.
   И внешний текст, и образ используют ОДИН кодировщик и те же ID. Порядок и
   повторяющиеся цифры не теряются. Роли/удержание цели остаются управляющими
   вхождениями; отдельные копии содержимого для «цели» и «зрения» не создаются.
4. Сначала дать образ FIELD=2345 при открытом окне. I растёт; S соответствующего
   поля/символов равно нулю. Обратная волна по опытным связям видна; кликов нет.
5. Снять поддержку: I затухает. Мир, веса, наблюдение не изменяются.
6. Явно разрешить «Достичь образа»: образ возбуждает старую сеть переходов,
   получаем X → CALC → 2 → 3 → 4 → 5. Рецепты нажатий в образ не записаны.
7. После подтверждённого ввода S зажигает ТОТ ЖЕ набор ID. Совпадение всех
   составляющих, включая поле и конец, разрешает погашение цели.

## Уравнения и границы

Для каждого представления:

```
I' = clip(d * I + (1-d) * внутренний_вход)
S' = clip(d * S + (1-d) * сенсорный_вход)
готовность = min(I требуемых компонентов)
сенсорное_совпадение = min(present ? S : 0 для требуемых компонентов)
```

Начальные коэффициенты: d=0,5; оба входа максимум 1; порог 0,7. Нормированные
уровни, не величины, измеренные на нейронах. `min` реализует обязательность
всех признаков: среднее не разрешает принять «234» или «2435» за «2345».
Требование поля связывает содержание с местом, а END проверяет длину.

Образ подаёт уровень `готовность` в ту же обратную взвешенную волну цели,
которая уже используется планировщиком. Нулевая I действительно прекращает
исполнение; обнулённые обратные связи не обходятся скрытым поиском маршрута.
Старые контекстные фрагменты сохраняют связи `next`; это не переписывание
всего Kolos как биофизической спайковой сети.

I и S не суммируются для доказательства реальности. Предсказание действия тоже
не является источником S. Источником остаётся host observation: симулятор в
браузере, свежий Glaz/UIA на ПК. Пока ждём квитанцию, наблюдаемая физика не
принимается ядром как подтверждённое действие. Квитанция с маркировкой
`source=imagined` отвергается. Это разделение источников внутри доверенного
адаптера, а не криптографическая защита от произвольной подмены памяти процесса.

`present` обнуляет доказательность исчезнувшего признака немедленно, даже если
его S ещё затухает. Пауза не двигает логические такты. При подтверждённом
завершении выполнение автоматически останавливается, поэтому оставшиеся следы
не обязаны обнулиться мгновенно. История и JSON-повтор работают только на копиях.

## Чего этот опыт не делает

Цель пока задаётся структурированно, а не понимается из русской фразы. Парсера
«сделай так, чтобы…», regexp выделения числа и внешней языковой модели нет.
Этот опыт — подготовка представления, которое позднее может возбуждаться
обученными языковыми связями. Языковое обобщение здесь не заявляется.

Никакое новое число не учится как готовый сценарий; символы должны быть известны.
Невозможно стереть неучтённый чужой текст: при конфликте содержимого применяется
прежняя остановка. Неизвестные состояния/пути не выводятся из фантазии.
Образ результата — не сгенерированная картинка и не мысленный прогон физики мира.
Сеть распространяет ожидание результата без физического исполнения.

## Проверки

Обязательный опыт 11 и отдельные проверки механизмов:
- сильный I без соответствующего S: нет ложного успеха, кликов или клавиш;
- I=0, сенсорный вход=0 или нулевые обратные веса: нет скрытого успешного пути;
- 1001, 1111, другая длина, пустая строка: сохранены позиции и границы;
- 2435, 234, 23450 и верный текст в другом поле не совпадают с целью;
- исчезновение внешнего признака не компенсируется остаточным S;
- правильное уже имеющееся содержимое подтверждается без лишнего ввода;
- физический ввод без доставки квитанции не гасит исходное вхождение;
- мнимая квитанция отвергается; JSON/история/пауза не имеют эффектов;
- Python/JS: сравниваются все вершины I/S, связи и подтверждения на каждом такте.

Браузер: «Состояния и цели» → «11 Образ цели». Сначала 8 тактов просмотра и
автопауза без действий. «Снять поддержку» показывает затухание. «Достичь образа»
запускает выполнение. Свой образ задаётся через конструктор целей → «Представить
без действий». «Проверить опыт 11» работает на отдельной копии.

Glaz: в существующем диалоге «Задать цель» есть «Представить без действий».
«Образ I / S» показывает те же источники в Python. Достижение требует прежнего
разрешения управления, F9 и свежих наблюдений. `/imagerytest` — только модель.
Новые функции Glaz не означают проверку всех сценариев в приложениях пользователя.

```
cd web && npm run test:imagery
npm run test:acceptance
npm run test:acceptance:browser
# из корня
python -m kolos_states.imagery_experiment
python -m unittest discover -s tests/desktop -p test_imagery.py -v
```

Полная приёмка добавляет опыт 11 к обязательным 1–10; дорогой перебор остаётся
отдельным. Непройденное или пропущенное нельзя записывать как PASS.

точной биологической реализации источников): Gerstner et al., Neuronal Dynamics,
https://neuronaldynamics.epfl.ch/online/Ch1.S3.html .
