# Kolos — лаборатория графа

Браузерная версия текстового ядра с настоящими изменениями памяти: точки,
связи, сигналы, пошаговое выполнение, пауза, скорость 0,25–5 с/шаг,
продолжение по памяти, реакции, история, JSON и локальное автосохранение.

## Открыть без установки

Готовый `index.html` из артефакта `kolos-browser-app` в GitHub Actions
открывается в браузере двойным щелчком. HTML автономен: сети, сервера и
ключей не требует. При запрете браузером локального хранилища используйте
«Экспорт JSON» или страницу GitHub Pages. Навигация file:// может быть
запрещена корпоративными настройками браузера.

## Открыть по постоянной ссылке

Workflow `Kolos Browser Lab` тестирует web/ и создаёт ветку
`gh-pages-graph-lab`, содержащую **только** `index.html` и `.nojekyll`.
После успешного запуска один раз выберите в репозитории:

Settings → Pages → Deploy from a branch → gh-pages-graph-lab → /(root) → Save.

Для приватного репозитория доступность Pages зависит от тарифа GitHub.
Обычный Pages-сайт публичен даже при приватном исходном репозитории.
Не делайте весь Kolos публичным. Базы, логи и пользовательская память
в сборку не входят. Workflow не меняет видимость репозитория и сам не
включает Pages. Если записи в ветку не разрешены, готовый HTML останется
в артефакте сборки, а шаг синхронизации покажет ошибку.

## Учебный пример

Нажмите «Пример абв» либо вручную: введите `абв` → дождитесь записи →
«Правильно» → «Новая попытка» → введите `аб` → «Продолжить по памяти».
Ответ: `в`, затем достижение poz. На каждой стрелке перечислены отдельные
ID связей; они объединяются только на рисунке. Новый ID при воспроизведении
не заменяет старую связь.

## Виртуальный экран и обучение действиям

Панель «Виртуальный экран» позволяет проверять поведение desktop-сценариев
без настоящего управления ОС. Объекты `DOC`, `CALC`, `SET`, `MAIL`
можно перетаскивать, скрывать и переставлять.

Сценарий «добавь траты 1700»:

1. Введите запрос и дождитесь конца записи текста.
2. Нажмите «Начать обучение».
3. Кликните `CALC`. В буфер демонстрации попадут три действия:
   `POS x,y → CHECK CALC → CLICK CALC`.
4. В поле «Клавиатура» введите `1700`: четыре отдельных `KEY`.
5. Escape или «Закончить», затем «Сохранить демонстрацию».
6. После записи действий нажмите «Правильно».
7. «Новая попытка» → при необходимости «Перемешать» → снова введите запрос →
   «Продолжить по памяти».

Перед `CHECK` и `CLICK` приложение проверяет виртуальный экран. Если
`CALC` переехал, курсор переносится на найденный объект. Если `CALC`
скрыт/отсутствует, цепочка останавливается до клика и клавиш. Это проверяет
правило «лучше не кликнуть, чем кликнуть не тот объект».

Пробел вне поля ввода — пуск/пауза, стрелка вправо — один шаг. Ползунок
истории и повтор — только просмотр, а не повторное обучение. Для возврата
к вводу нажмите «К текущему состоянию». Отмена очереди не стирает уже
записанные шаги. «Очистить граф» требует подтверждения и не трогает desktop-базу.

## Разработка

На Windows можно запустить лабораторию двойным щелчком по файлу
`Лаборатория Колос.bat` в корне проекта. При первом запуске он установит
зависимости, затем откроет страницу в браузере. Окно запуска нужно оставить
открытым на время работы.

Node.js 20+ и Python 3 для SQLite-эталона:

```sh
cd web
npm ci
npm test
npm run dev
```

Локальная страница: http://127.0.0.1:4173. `npm run build` создаёт
`dist/index.html`. TypeScript 5.8.3 закреплён; внешних runtime-зависимостей нет.

Дополнительная проверка браузера:

```sh
python -m pip install playwright
python -m playwright install chromium
python tests/browser_smoke.py
```

При ограничении навигации в тестовом контейнере:
`KOLOS_INLINE_TEST=1 python tests/browser_smoke.py`.
Этот режим проверяет DOM/анимацию и обработку отказа хранилища, но **не**
подтверждает IndexedDB-перезагрузку (об этом явно написано в результате).
Обычный HTTP-режим дополнительно проверяет настоящее восстановление IDB.

## Архитектура

- `src/engine.ts` — детерминированное ядро без DOM, preview/commit и журнал.
- `src/graph.ts` — SVG, группировка, подписи, точная геометрия импульса.
- `src/app.ts` — управление, история, интерфейс и настройки.
- `src/storage.ts` — IndexedDB; ошибки отображаются. Вторая вкладка
  не перезаписывает автосохранение первой при поддержке Web Locks.
- `tests/` — 20 тестов ядра, SQLite-эталон и сценарий браузера.

Границы переноса, начальное состояние и исправления исходника описаны
в [ALGORITHM.md](ALGORITHM.md). Это текстовая лаборатория, не полный
перенос Kolos/Glaz и не управление компьютером.
