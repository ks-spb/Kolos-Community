# Нейронный просмотр Kolos: план, реализация и проверка

## Задача и граница

Показать, какие вершины текущего алгоритма активны, по каким связям передаётся
сигнал, почему выбран переход и когда подтверждение освобождает следующий символ.
Это диагностическое представление States, не замена алгоритма и не биофизический
симулятор мозга. Математика core / imagery / goal-network / language не изменена.

## План реализации

1. Читать реальные снимки ядра и события, не выводить маршрут из номера теста.
2. Раздельно показывать I (внутренний образ), S (принятое наблюдение), A (хранимая
   активация) и C (кандидат на выбор). Не выдавать сброшенную A за прошлое C.
3. Изобразить вершины кругами; добавить направление, ID, веса и движение вкладов.
   Группировать только одинаково направленные связи одного типа/источника данных;
   IDs показывать через запятую, обратные связи оставлять отдельно.
4. Добавить выбор слоёв, поиск, масштаб, инспектор с формулой, историю, шаги и
   регулируемый интервал. История не должна повторно выполнять действия.
5. Дать отдельный офлайн-стенд 11/12 и просмотр ТОГО ЖЕ движка из основной лаборатории.
6. Подключить к Glaz защищённый просмотр только для чтения. Управление ядром не
   передавать в локальный HTTP API. Проверить инвариантность и отрицательные случаи.

## Запуск

Браузер: `npm run build` в web создаёт `dist/index.html` (прежняя лаборатория с
кнопкой «Нейроны · живой граф») и `dist/neurons.html` (отдельный офлайн-стенд).
В отдельном стенде опыт 11 выбран по умолчанию, значение 2345. Пуск делает 8 тактов
представления и останавливается. «Снять поддержку» показывает затухание; «Достичь
образа» запускает прежний двигатель действий. Для опыта 12 выберите его в списке.

В основной лаборатории загрузите опыт 11 / своё состояние, затем нажмите «Нейроны ·
живой граф». Модальное окно управляет тем же экземпляром States, а не второй копией.
Изменения остаются в журнале/памяти лаборатории. Закрытие останавливает просмотр.

Glaz: обновить проект целиком → обычный `run_main.bat` → «Состояния и цели (ПК)» →
«Нейроны · живой граф». Откроется браузер по локальному адресу 127.0.0.1. Сервер
работает только пока открыт Glaz в этом режиме. Смена движка закрывает сервер.
Перед живым наблюдением запустите «Представить без действий» через конструктор
цели Glaz. Пауза / шаг / достижение / F9 настоящего ядра выполняются в самом Glaz.

**Пауза просмотра Glaz не останавливает алгоритм.** В этом окне нет командного API.
Используйте второй монитор: браузер, перекрывший целевые иконки на одном экране,
изменяет наблюдаемую среду. Другой вариант — сохранить просмотр и изучить его позже.
Изолированные кнопки «11: тест образа» проверяют отдельную модель, а не текущий
настольный граф: самотест не заменяет обучение реальным объектам.

## Что означает каждая связь

- `recorded` — число непосредственно из `event.flows` ядра.
- `equation` — подписанный член существующего уравнения (например прямой вход I
  или motor input + history); это диагностическая зависимость, не выученный синапс.
- `structure` — отношение в памяти без передачи на данном такте. Оно пунктирное.

Особенно важно: `imagery.edges: order` только хранит порядок представлений.
В действующем ядре I/S возбуждаются прямыми входами. По order НЕ идут импульсы I/S,
поэтому анимация по этим рёбрам запрещена. Источники нарисованы с пунктирным кругом
и подписью «источник / расчёт», а не как дополнительная выученная память.

В обратной волне `event.flows.value` — вклад до нормировки входящих связей и
утечки получателя. Инспектор отдельно показывает пересчитанный член после
`(1-decay)/число_входов`. Наличие сигнала не означает право кликнуть: учитываются
порог, допустимость состояния, refractory и конкуренция. C и A не подменяются.

## Управление

- Пуск / Один такт: считают настоящие такты в отдельном браузерном стенде.
- Интервал 0,1–3 с: меняет скорость просмотра, не коэффициенты затухания.
- Слои: образ и переходы, образ I/S, состояния и действия, символы, язык, вся память.
- Колесо: масштаб вокруг курсора; фон: перемещение; круг: перемещение вершины.
- Нажатие на круг/стрелку: параметры, ID, вес, вклад, прошлое и новое значение.
- Ползунок истории: только чтение. В прошлом запрещены «Достичь»/«Снять поддержку».
- Сохранение/открытие JSON: только снимки, без исполнения содержащихся действий.

Яркость круга берётся из максимума показанных каналов, численные каналы подписаны
раздельно. Звезда — выбранный кандидат. Частицы иллюстрируют завершённый расчёт,
а не являются моделью отдельных биологических спайков. Граф не движется сам по
себе на паузе; в ручном шаге показана фиксированная промежуточная позиция частицы.

## Ограничения наблюдения

Отдельный стенд хранит последние 500 снимков, Glaz — последние 80 снимков сырого
состояния. Запись Glaz включается только при открытии просмотра; открыв его поздно,
нельзя восстановить уже прошедшие такты. Пропуски буфера явно помечаются. На одном
рисунке не более 220 вершин; остальное доступно через выбор слоя и поиск. Это
ограничение рисунка, не усечение рабочей сети.

Во время ожидания ACK показывается принятое ядром наблюдение, а не воображаемый
результат. В браузерном стенде отдельно указывается, если физика уже поменяла
текст, но ядро ещё не приняло квитанцию. На ПК зрение/UIA остаются прежними; этот
просмотр не делает нечитаемое поле читаемым и не улучшает детекцию Glaz.

Локальный сервер: случайный порт, 127.0.0.1, токен сеанса в URL fragment / заголовке,
проверка Host/Origin, запрет POST/PUT/DELETE, статический allowlist, no-store, без
CORS. Снимки содержат тексты полей и команды текущего опыта и остаются на ПК.
Экспортируйте их только осознанно. Это не защита от вредоносного ПО в той же учётной
записи Windows. В репозиторий отправляются только код и синтетические тесты.

## Приёмка

`npm run test:neurons`, `npm run test:neurons:browser` (после build),
`python -m unittest discover -s tests/desktop -p test_neuron_view.py -v`.
Проверяются неизменность модели, точные I/S и flow-значения, отсутствие импульсов
по order, различие эффект/ACK, успешное 2345, язык, группировка направлений,
пауза/история/импорт, безопасные HTTP границы, ограничение записи и пропуски.
Прежние алгоритмические опыты 1–12 остаются обязательными.
